📐 HTML 分栏 · 横着分 & 竖着分

核心方法：使用 display: flex 配合 flex-direction: row（竖着分/左右）或 flex-direction: column（横着分/上下）。
👉 下方两个示例 只聚焦分栏结构，无多余样式干扰。

⬅️ 竖着分 · 左右排列

使用 flex-direction: row （默认值）
子项通过 flex: 1 平均分配宽度 → 等宽分栏

左栏
中栏
右栏
🔑 核心 CSS：
display: flex;  +  flex-direction: row;  +  flex: 1; （子项等宽）

⬇️ 横着分 · 上下排列

使用 flex-direction: column
子项默认垂直排列，高度由内容撑开（也可用 flex: 1 等分高度）

上栏
中栏
下栏
🔑 核心 CSS：
display: flex;  +  flex-direction: column;
（子项高度默认自适应，若想等分可用 flex: 1）

✅ 记忆口诀：
· flex-direction: row → 竖着分（左右并排）
· flex-direction: column → 横着分（上下堆叠）
· 子项用 flex: 1 可等分主轴空间。
