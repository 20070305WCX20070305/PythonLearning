## 正文

### 1.1 第一个程序与编译流程

新建 `hello.c`：

```c
#include <stdio.h>      /* 引入 printf 的声明 */
int main(void)          /* 程序入口；void 表示不接受参数 */
{
    printf("Hello, C!\n");   /* \n 表示换行 */
    return 0;                /* 返回 0 表示正常结束 */
}
```

编译并运行（后续命令都在 WSL2 Ubuntu 里执行），预期输出 `Hello, C!`：

```bash
gcc hello.c -o hello     # -o 指定输出文件名
./hello                  # 运行
```

`gcc` 的工作分成四步，可以用选项让它停在中间：

```bash
gcc -E hello.c -o hello.i   # 1. 预处理：展开 #include、#define
gcc -S hello.i -o hello.s   # 2. 编译：把 C 变成汇编
gcc -c hello.s -o hello.o   # 3. 汇编：生成机器码目标文件
gcc hello.o -o hello        # 4. 链接：把目标文件和库拼成可执行文件
```

常见错误：

- 忘记分号：错误信息常指向「上一行的末尾」，要看错误行号的前一行。
- 中文标点：写成 `printf("你好"）；`（全角括号/分号）会报一堆莫名其妙的错。
- 用 `./hello.c` 直接运行源码：`Permission denied`，要先编译。

### 1.2 基本类型与 sizeof

```c
#include <stdio.h>
int main(void)
{
    printf("char      : %zu 字节\n", sizeof(char));
    printf("short     : %zu 字节\n", sizeof(short));
    printf("int       : %zu 字节\n", sizeof(int));
    printf("long      : %zu 字节\n", sizeof(long));
    printf("long long : %zu 字节\n", sizeof(long long));
    printf("float     : %zu 字节\n", sizeof(float));
    printf("double    : %zu 字节\n", sizeof(double));
    printf("指针      : %zu 字节\n", sizeof(void *));
    return 0;
}
```

编译运行：`gcc -Wall -Wextra -std=c11 sizes.c -o sizes && ./sizes`。在 WSL2（x86_64）上的输出依次是：`1 2 4 8 8 4 8 8` 字节。

注意：`long` 在 64 位 Linux 上是 8 字节，在 32 位系统或 Windows 上可能是 4 字节；跨平台时用 `long long` 或 `<stdint.h>` 里的 `int64_t`。`sizeof` 返回 `size_t`，用 `%zu` 打印。

常见错误：

- 用 `%d` 打印 `sizeof`：类型不匹配，输出错乱；用 `%zu`。
- 以为溢出会自动变成大数：有符号整数溢出是未定义行为，做统计用 `long long`。

### 1.3 运算符

```c
#include <stdio.h>
int main(void)
{
    int a = 7, b = 2;
    printf("a / b = %d\n", a / b);          /* 整数除法，截断 */
    printf("a %% b = %d\n", a % b);         /* 打印 % 要写 %% */
    printf("a / 2.0 = %.2f\n", a / 2.0);    /* 一边是 double，按浮点算 */
    printf("a > b : %d\n", a > b);          /* 关系运算结果是 1 或 0 */
    printf("a & b : %d\n", a & b);          /* 按位与：111 & 010 = 010 */
    return 0;
}
```

预期输出依次为：`3`、`1`、`3.50`、`1`、`2`。优先级不用背全：不确定就加括号；`=` 和 `==` 是最常见的笔误。

常见错误：

- 把 `=` 写成 `==`（或反过来）：`if (x = 0)` 恒为假，还会把 x 改掉。
- 位运算与逻辑运算混淆：`&` 是按位与、`&&` 是逻辑与。
- 负数取模：`-7 % 2` 在 C99 里是 `-1`，与 Python 的 `1` 不同。

### 1.4 控制流

```c
#include <stdio.h>
int main(void)
{
    int sum = 0;
    for (int i = 1; i <= 100; i++)   /* 循环变量可以在 for 里声明（C99 起） */
        sum += i;
    printf("1+2+...+100 = %d\n", sum);

    int n = 5;
    while (n > 0) {                  /* while: 条件为真就执行 */
        printf("%d ", n);
        n--;
    }
    printf("\n");

    int grade = 85;
    if (grade >= 90)
        printf("优秀\n");
    else if (grade >= 60)
        printf("及格\n");
    else
        printf("不及格\n");

    switch (grade / 10) {            /* switch 只接受整数/枚举 */
        case 9:  printf("等级 A\n"); break;
        case 8:  printf("等级 B\n"); break;
        default: printf("等级其他\n"); break;
    }
    return 0;
}
```

预期输出：`1+2+...+100 = 5050`、`5 4 3 2 1`、`及格`、`等级 B`。

常见错误：

- `switch` 里漏 `break` 会发生「贯穿」，继续执行下一个 `case`。
- `if (0 <= x <= 10)` 不是范围判断，要写 `0 <= x && x <= 10`。
- `for` 循环里写 `i <= n` 却从 0 开始，导致多执行一次（数组越界常由此而来）。

### 1.5 函数与声明

```c
#include <stdio.h>
int gcd(int a, int b);          /* 函数声明（原型），让 main 先知道它的存在 */

int gcd(int a, int b)           /* 函数定义 */
{
    while (b != 0) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

int main(void)
{
    printf("gcd(48, 36) = %d\n", gcd(48, 36));
    return 0;
}
```

预期输出：`gcd(48, 36) = 12`。C 的参数是「值传递」：函数内改形参不影响外面；想修改外部变量得传指针（02 篇讲）。

常见错误：

- 调用在定义之前又没有原型声明：C99 以后会报隐式声明错误。
- 声明与定义的参数类型不一致：链接时报 `undefined reference`。
- 函数里定义同名局部变量遮蔽全局变量，读代码时容易混淆。

### 1.6 数组与字符串

C 的数组不检查下标，`a[10]` 编译器可能不报错，运行时才出问题（02 篇用 ASan 抓）。`sizeof(数组)` 是总字节数；元素个数用 `sizeof(a) / sizeof(a[0])`。

```c
#include <stdio.h>
#include <string.h>
int main(void)
{
    int a[5] = {10, 20, 30, 40, 50};
    printf("a[2] = %d, sizeof(a) = %zu, 元素个数 = %zu\n",
           a[2], sizeof(a), sizeof(a) / sizeof(a[0]));

    char name[16];
    const char *hello = "hello";              /* 字符串是以 '\0' 结尾的 char 数组 */
    strncpy(name, hello, sizeof(name) - 1);   /* 拷贝不超过缓冲区 */
    name[sizeof(name) - 1] = '\0';            /* 保险起见手动补 '\0' */
    printf("name = %s, 长度 = %zu\n", name, strlen(name));

    char buf[32];
    int n = snprintf(buf, sizeof(buf), "%s-%d", name, 2026);   /* 安全格式化 */
    if (n < 0 || (size_t)n >= sizeof(buf))
        fprintf(stderr, "输出被截断\n");
    else
        printf("buf = %s\n", buf);

    printf("strcmp(abc, abd) = %d\n", strcmp("abc", "abd"));   /* <0 表示前面小 */
    return 0;
}
```

预期输出包含：`a[2] = 30, sizeof(a) = 20, 元素个数 = 5`、`name = hello, 长度 = 5`、`buf = hello-2026`、`strcmp(abc, abd) = -1`。

要点：`strlen` 数到 `'\0'` 为止（不含）；拷贝用 `strncpy` 并手动补 `'\0'`；格式化用 `snprintf`；**永远不要用 `gets`**，读一行用 `fgets`。

常见错误：

- `char s[5]; strcpy(s, "hello");`：需要 6 字节（含 `'\0'`），越界。
- `if (strcmp(a, b))` 把「相等」当条件：相等返回 0，应写 `strcmp(a, b) == 0`。
- 函数参数里的 `char s[]` 实际是指针，`sizeof` 得 8 而不是字符串长度。

### 1.7 struct、enum 与 typedef

```c
#include <stdio.h>
#include <string.h>

typedef enum {          /* 枚举：给一组整数起名字 */
    STATE_IDLE,         /* 0 */
    STATE_RUNNING,      /* 1 */
    STATE_DONE          /* 2 */
} State;

struct particle {               /* 结构体：把不同类型的数据打包 */
    char name[32];
    double mass;                /* 单位：MeV/c^2 */
    int charge;
};
typedef struct particle Particle;   /* 起个别名，之后可以直接写 Particle */

int main(void)
{
    Particle p;
    strncpy(p.name, "electron", sizeof(p.name) - 1);
    p.name[sizeof(p.name) - 1] = '\0';
    p.mass = 0.511;
    p.charge = -1;
    printf("粒子 %s: 质量 %.3f, 电荷 %d\n", p.name, p.mass, p.charge);

    Particle *pp = &p;              /* 结构体指针访问成员用 -> */
    printf("通过指针: %s\n", pp->name);

    State st = STATE_RUNNING;
    printf("状态 = %d\n", (int)st);
    return 0;
}
```

预期输出：`粒子 electron: 质量 0.511, 电荷 -1`、`通过指针: electron`、`状态 = 1`。

注意：`struct` 只是把数据打包在一起，本身不带方法；本阶段把数据和操作数据的函数分开写即可，不需要用函数指针去模拟对象。

常见错误：

- `struct particle` 定义末尾漏分号。
- 访问指针成员写成 `pp.name`（应为 `pp->name`）。
- 用 `memcmp` 比较结构体：可能有填充字节，应逐字段比较。

### 1.8 标准输入输出

```c
#include <stdio.h>
int main(void)
{
    char line[64];
    char name[64];
    int age;
    double height;

    printf("请输入 姓名 年龄 身高(cm)，例如: wang 19 175.5\n");
    if (fgets(line, sizeof(line), stdin) == NULL) {   /* 读一整行，安全 */
        fprintf(stderr, "读取输入失败\n");
        return 1;
    }
    if (sscanf(line, "%63s %d %lf", name, &age, &height) != 3) {
        fprintf(stderr, "格式不对，应输入: 姓名 年龄 身高\n");
        return 1;
    }
    printf("姓名=%s 年龄=%d 身高=%.1f\n", name, age, height);
    return 0;
}
```

运行示例：`echo "wang 19 175.5" | ./input` 输出 `姓名=wang 年龄=19 身高=175.5`。

常用格式串：`%d`(int)、`%ld`(long)、`%lld`(long long)、`%u`(unsigned)、`%f`/`%lf`(打印 float / scanf 的 double)、`%c`、`%s`、`%zu`(size_t)、`%p`(指针)。

常见错误：

- `scanf("%d", age)` 少了 `&`：运行时崩溃。
- `scanf("%s", buf)` 不限制长度：输入超长就溢出；用宽度 `%15s` 或先 `fgets` 再 `sscanf`。
- `printf("%d", 3.14)`：格式串与参数类型必须严格对应。

### 1.9 头文件与多文件编译

`math_utils.h`（头文件保护防止重复展开）：

```c
#ifndef MATH_UTILS_H
#define MATH_UTILS_H
int add(int a, int b);
long long square(long long x);
#endif
```

`math_utils.c`：

```c
#include "math_utils.h"
int add(int a, int b) { return a + b; }
long long square(long long x) { return x * x; }
```

`main.c`：

```c
#include <stdio.h>
#include "math_utils.h"     /* 自己的头文件用双引号 */
int main(void)
{
    printf("add(2, 3) = %d\n", add(2, 3));
    printf("square(12) = %lld\n", square(12));
    return 0;
}
```

编译（把所有 `.c` 一起交给 gcc），预期输出 `add(2, 3) = 5` 与 `square(12) = 144`：

```bash
gcc -Wall -Wextra -std=c11 main.c math_utils.c -o app
./app
```

常见错误：

- 头文件里定义函数体：多个 `.c` 包含它会导致「重复定义」链接错误。
- 头文件漏掉 `#ifndef` 保护：重复包含会报错。
- `gcc main.c` 忘了带上 `math_utils.c`：链接时报 `undefined reference to 'add'`。

### 1.10 与 Python 的对照

| 主题   | Python                | C                                                   |
| ------ | --------------------- | --------------------------------------------------- |
| 变量   | `x = 1`，类型动态   | `int x = 1;`，类型固定、可溢出                    |
| 字符串 | 不可变、长度自带      | `char` 数组 + `'\0'`，长度自己盯                |
| 列表   | `list`，自动扩容    | 固定长度数组；动态扩容需`malloc/realloc`（见 02） |
| 函数   | 参数传递本质是引用    | 值传递；改动外部变量要传指针                        |
| 输入   | `input()`           | `fgets` + `sscanf`，注意缓冲与长度              |
| 输出   | `print(f"{x:.2f}")` | `printf("%.2f\n", x)`，格式串必须匹配             |
| 错误   | 异常                  | 返回值 +`errno`，必须主动检查                     |

## 练习

1. 温度转换器：从标准输入读一个摄氏温度（浮点），输出华氏温度，保留两位小数。公式 `F = C * 9 / 5 + 32`。
   提示：用 `fgets` + `sscanf`，注意整数除法陷阱。验收：`echo 100 | ./temp` 输出 `212.00`；`echo -40 | ./temp` 输出 `-40.00`。
2. 打印乘法表：读入 `n`（1~9），输出 `n x 1` 到 `n x 9`，每行一个。
   提示：`for` 循环 + `printf("%d x %d = %d\n", ...)`。验收：输入 7 时包含 `7 x 9 = 63` 共 9 行。
3. 素数表：写函数 `int is_prime(int n)`，输出 1~200 内的素数，每行 10 个，行末不要多余空格。
   提示：试除到 `i * i <= n`；`1` 不是素数。验收：肉眼确认包含 2、97、199 且每行 10 个。
4. 粒子结构体：定义 `Particle`（名称、质量、电荷），读入 3 个粒子，用冒泡排序按质量升序输出（交换结构体可以直接整体赋值）。
   提示：输入格式 `名称 质量 电荷`，用 `fgets` + `sscanf`。验收：输出顺序正确且格式整齐。
5. 多文件改造：把练习 3 的 `is_prime` 和练习 4 的排序拆成 `utils.h` / `utils.c` / `main.c`。
   提示：头文件加 include guard；声明放 `.h`，定义放 `.c`。验收：`gcc -Wall -Wextra -std=c11 main.c utils.c -o app` 无警告，结果一致。
