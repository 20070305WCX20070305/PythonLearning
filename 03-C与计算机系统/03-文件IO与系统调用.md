## 正文

### 3.1 系统调用：用户态与内核态

你的 C 程序运行在**用户态**，不能直接碰硬盘、网卡等硬件。想读写文件，必须通过**系统调用**（system call）请求内核代劳：

```
用户程序                    内核
  |  read(fd, buf, n)        |
  |------------------------->|  切换内核态、找到 fd 对应的文件
  |  返回实际读到的字节数       |  把数据拷回用户缓冲区、切回用户态
  |<-------------------------|
```

你调用的 `read()`、`write()` 其实是 glibc 提供的**包装函数**，真正的系统调用由 CPU 特殊指令触发。查手册时用 `man 2 open`（第 2 节 = 系统调用）与 `man 3 printf`（第 3 节 = C 标准库）。可选安装 `strace` 观察程序实际发了哪些系统调用（`strace -c ./mycat sample.txt`）。

常见错误：

- 把系统调用当普通函数用，不检查返回值：失败时返回 -1 并设置 `errno`。
- 用 `man open` 却看到 X11 的 `open`：加 `2` 或 `3` 指定章节。
- 认为 `printf` 直接写文件：它先写用户态缓冲区，之后才调 `write`。

### 3.2 文件描述符

**文件描述符（file descriptor, fd）是一个小整数**，代表「进程打开的一个文件、管道或设备」。每个进程启动时自带三个：

| fd | 名称 | 通常指向 |
| --- | --- | --- |
| 0 | 标准输入 stdin | 键盘 / 重定向的输入文件 |
| 1 | 标准输出 stdout | 终端 / 重定向的输出文件 |
| 2 | 标准错误 stderr | 终端（不受 `>` 影响） |

`open` 成功时返回当前最小的可用 fd。所以「重定向 `>`」在操作系统层面就是「把 fd 1 换成另一个文件的描述符」（项目的重定向里程碑会亲手做一次）。不用打开文件也能读写 fd 0/1：

```c
#include <stdio.h>
#include <unistd.h>
int main(void)
{
    char buf[16];
    ssize_t n = read(0, buf, sizeof(buf));        /* 从标准输入读 */
    if (n < 0) { perror("read"); return 1; }
    ssize_t written = write(1, buf, (size_t)n);   /* 写到标准输出 */
    if (written < 0) { perror("write"); return 1; }
    return 0;
}
```

编译运行 `gcc -Wall -Wextra -std=c11 -g rwecho.c -o rwecho`，然后 `echo -n "hello" | ./rwecho` 输出 `hello`。

常见错误：

- `read` 的返回值是 `ssize_t`（有符号），不要和 `size_t` 混着比较。
- `write` 的长度写成 `sizeof(buf)` 而不是实际读到的 `n`：会把缓冲区里的垃圾也写出去。
- 以为 `read` 一定读满：它可能只读到一部分；`read` 返回 0 表示文件结束（EOF），不是错误。

### 3.3 open / read / write / close / lseek

```c
#define _POSIX_C_SOURCE 200809L
#include <errno.h>
#include <fcntl.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>

/* 循环写完，处理「一次 write 没写完」的情况 */
static int write_all(int fd, const char *buf, size_t len)
{
    size_t done = 0;
    while (done < len) {
        ssize_t n = write(fd, buf + done, len - done);
        if (n < 0) {
            if (errno == EINTR)      /* 被信号打断，重试 */
                continue;
            return -1;
        }
        done += (size_t)n;
    }
    return 0;
}

int main(void)
{
    const char *text = "first line\nsecond line\n";
    int fd = open("demo.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd < 0) { perror("open"); return 1; }
    if (write_all(fd, text, strlen(text)) < 0) {
        perror("write"); close(fd); return 1;
    }
    if (close(fd) < 0) { perror("close"); return 1; }
    printf("已写入 demo.txt\n");
    return 0;
}
```

编译运行后 `cat demo.txt` 看到两行文本，`ls -l demo.txt` 权限为 `-rw-r--r--`。

`open` 常用标志（用 `|` 组合）：

| 标志 | 含义 |
| --- | --- |
| `O_RDONLY` / `O_WRONLY` / `O_RDWR` | 只读 / 只写 / 读写（三选一） |
| `O_CREAT` | 文件不存在就创建，需提供第三个参数权限 |
| `O_TRUNC` | 打开时清空原内容 |
| `O_APPEND` | 每次写都追加到文件末尾 |

权限 `0644` 是八进制（文件主读写、其他只读），实际权限是 `mode & ~umask`（通常 umask 为 022）。`lseek` 移动读写位置，也可用来量文件大小（下面是片段，放在已打开 fd 的函数里）：

```c
off_t size = lseek(fd, 0, SEEK_END);   /* 移到末尾，返回偏移量即文件大小 */
if (size < 0) { perror("lseek"); }
/* SEEK_SET 从开头算、SEEK_CUR 从当前位置算、SEEK_END 从末尾算 */
```

常见错误：

- `open` 带 `O_CREAT` 却忘记第三个参数：文件权限随机，编译器警告不要忽略。
- `open` 返回 -1 后继续 `write(-1, ...)`：立刻失败，还可能把错误信息覆盖掉。
- 假设 `read`/`write` 一定完成请求的字节数：网络、管道、大文件都可能分批，稳妥写法是循环。

### 3.4 errno 与 perror

出错时系统调用返回 -1（或 `NULL`），并把原因写进全局变量 `errno`。`perror` 会把你的提示和错误描述一起打印到 stderr：

```c
#include <errno.h>
#include <fcntl.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>
int main(void)
{
    int fd = open("no_such_file.txt", O_RDONLY);
    if (fd < 0) {
        perror("open no_such_file.txt");    /* 输出 ...: No such file or directory */
        fprintf(stderr, "errno=%d (%s)\n", errno, strerror(errno));
        return 1;
    }
    close(fd);
    return 0;
}
```

常见错误：

- 在调用下一个可能失败的函数之后才看 `errno`：它会被覆盖，要**立即**保存或打印。
- 用 `printf` 而不是 `fprintf(stderr, ...)` 报错：错误信息应进 stderr，便于重定向时分流。

### 3.5 stat：查看文件信息

```c
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <sys/stat.h>

int main(int argc, char *argv[])
{
    struct stat st;
    if (argc != 2) {
        fprintf(stderr, "用法: %s <文件>\n", argv[0]);
        return 1;
    }
    if (stat(argv[1], &st) < 0) { perror("stat"); return 1; }

    printf("大小: %lld 字节\n", (long long)st.st_size);
    printf("类型: %s\n", S_ISREG(st.st_mode) ? "普通文件" :
                        S_ISDIR(st.st_mode) ? "目录" : "其他");
    return 0;
}
```

编译运行：`gcc -Wall -Wextra -std=c11 -g filestat.c -o filestat`，`./filestat demo.txt` 输出 `大小: 23 字节` 与 `类型: 普通文件`。

`struct stat` 常用字段：`st_size`（字节数）、`st_mode`（类型 + 权限）、`st_mtime`（修改时间）。类型判断用宏 `S_ISREG`、`S_ISDIR`、`S_ISLNK`。

常见错误：

- 把 `st_mode` 直接和 `S_IFREG` 比：应使用 `S_ISREG(st.st_mode)` 宏。
- `st_size` 类型是实现定义的整数，打印时转成 `long long`。

### 3.6 标准 IO 与系统调用：区别与缓冲

C 标准库的 `FILE *`（`fopen/fread/fwrite/fprintf`）是建立在系统调用之上的**带缓冲**封装：

| | 系统调用 | 标准 IO |
| --- | --- | --- |
| 代表函数 | `open/read/write` | `fopen/fread/fwrite/fprintf` |
| 句柄 | `int` fd | `FILE *` |
| 缓冲 | 无用户态缓冲 | 有（按块/按行），可用 `fflush` 强制刷出 |
| 格式化 | 需自己拼字符串 | `fprintf/scanf` 直接支持 |
| 适用 | 精细控制、管道、重定向 | 日常文本读写、格式化 |

缓冲的坑：

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
int main(void)
{
    printf("这一行走标准 IO，先进缓冲区\n");
    const char *msg = "这一行走 write，直接进内核\n";
    if (write(1, msg, strlen(msg)) < 0) { perror("write"); return 1; }
    fflush(stdout);      /* 不加这句，重定向到文件时两行顺序可能颠倒 */
    return 0;
}
```

在终端上顺序正常（行缓冲），`./mix_io > out.txt` 后 `cat out.txt` 则可能先看到 write 那行（stdout 变成全缓冲，退出时才刷）。规则：**不要在同一文件上混用 `FILE *` 和 fd**；非混不可时，先用 `fflush(fp)` 把缓冲刷出去，或 `fileno(fp)` 拿到 fd 后小心操作。

常见错误：

- 程序崩溃前用 `printf` 打的日志没出现：缓冲区没来得及刷；调试日志用 `fprintf(stderr, ...)`（stderr 默认不缓冲）。
- 以为 `fwrite` 返回成功就一定落盘：只是写进了缓冲区；需要时用 `fflush`。
### 3.7 目录遍历：opendir / readdir / closedir

```c
#define _POSIX_C_SOURCE 200809L
#include <dirent.h>
#include <errno.h>
#include <stdio.h>
#include <string.h>

int main(int argc, char *argv[])
{
    const char *path = (argc > 1) ? argv[1] : ".";
    DIR *dir = opendir(path);
    if (dir == NULL) { perror("opendir"); return 1; }

    errno = 0;                       /* 用 errno 区分「读完」和「出错」 */
    struct dirent *entry;
    while ((entry = readdir(dir)) != NULL) {
        if (strcmp(entry->d_name, ".") == 0 || strcmp(entry->d_name, "..") == 0)
            continue;
        printf("%s\n", entry->d_name);
    }
    if (errno != 0) { perror("readdir"); closedir(dir); return 1; }
    if (closedir(dir) < 0) { perror("closedir"); return 1; }
    return 0;
}
```

编译运行 `./listdir /etc | head -n 5`，输出 `adduser.conf`、`alternatives` 等（具体内容因机器而异，顺序不是字典序）。

常见错误：

- 忘记跳过 `.` 和 `..`。
- 把 `readdir` 返回 `NULL` 一律当出错：正常读完也返回 `NULL`，要看 `errno`。
- 拼接路径忘了斜杠：`snprintf(full, sizeof(full), "%s/%s", path, name);` 是安全写法。

### 3.8 综合示例：简化版 wc

统计文件的行数、单词数、字节数，输出格式与系统 `wc` 一致：

```c
#define _POSIX_C_SOURCE 200809L
#include <fcntl.h>
#include <stdio.h>
#include <unistd.h>

#define BUF_SIZE 4096

static int count_file(const char *path, long long *lines,
                      long long *words, long long *bytes)
{
    int fd = open(path, O_RDONLY);
    if (fd < 0) { perror(path); return -1; }

    char buf[BUF_SIZE];
    ssize_t n;
    long long l = 0, w = 0, b = 0;
    int in_word = 0;                 /* 上一个字节是不是单词的一部分 */

    while ((n = read(fd, buf, sizeof(buf))) > 0) {
        b += n;
        for (ssize_t i = 0; i < n; i++) {
            if (buf[i] == '\n')
                l++;
            if (buf[i] == ' ' || buf[i] == '\n' || buf[i] == '\t') {
                in_word = 0;
            } else if (!in_word) {
                in_word = 1;
                w++;
            }
        }
    }
    if (n < 0) { perror("read"); close(fd); return -1; }
    close(fd);
    *lines = l; *words = w; *bytes = b;
    return 0;
}

int main(int argc, char *argv[])
{
    if (argc < 2) {
        fprintf(stderr, "用法: %s <文件> [文件...]\n", argv[0]);
        return 1;
    }
    long long total_l = 0, total_w = 0, total_b = 0;
    for (int i = 1; i < argc; i++) {
        long long l, w, b;
        if (count_file(argv[i], &l, &w, &b) < 0)
            return 1;
        printf("%7lld %7lld %7lld %s\n", l, w, b, argv[i]);
        total_l += l; total_w += w; total_b += b;
    }
    if (argc > 2)
        printf("%7lld %7lld %7lld 总计\n", total_l, total_w, total_b);
    return 0;
}
```

编译并对比：

```bash
gcc -Wall -Wextra -std=c11 -g mywc.c -o mywc
printf 'hello world\nfoo bar baz\n' > sample.txt
./mywc sample.txt
wc sample.txt
```

两边都输出 `2 5 24 sample.txt`。

常见错误：

- `in_word` 声明在循环内部：跨缓冲区边界的单词会被少数或多数，必须放在循环外。
- 用 `char` 接收 `read` 的返回值：遇到错误或大文件会出错，必须用 `ssize_t`。
- 打开失败后继续统计：会打印垃圾结果，应该报错并返回。

### 3.9 与 Python 的对照

| 主题 | Python | C |
| --- | --- | --- |
| 打开文件 | `open(path, "r")` 返回文件对象 | `open` 返回 fd，或 `fopen` 返回 `FILE *` |
| 关闭 | `with` 自动关闭 | 手动 `close` / `fclose`，每个分支都要照顾到 |
| 读 | `.read()` / 迭代行 | `read` 循环 + 自己切行 |
| 错误 | 抛异常，`try/except` | 返回 -1 / NULL + `errno`，逐个检查 |
| 目录 | `os.listdir` / `pathlib` | `opendir/readdir` |
| 文件信息 | `os.stat` 返回对象 | `stat` 填充 `struct stat` |

Python 的 `open()` 默认也是带缓冲的文本 IO，本质上包着和这里一样的 fd；`os.open` / `os.read` 则接近系统调用。

## 练习

1. `mycat`：实现 `./mycat file1 [file2 ...]`，把多个文件内容依次输出到 stdout；文件打不开时报错到 stderr 并继续处理下一个。
   提示：`open` + `read/write` 循环；用固定 4096 缓冲区。验收：`./mycat a.txt b.txt` 与 `cat a.txt b.txt` 输出一致。

2. `mycp`：实现 `./mycp src dst`，逐块复制文件；要求用 `open/read/write/close`，检查每一步返回值。
   提示：`O_WRONLY | O_CREAT | O_TRUNC, 0644`；不要用 `sendfile` 之类的高级接口。验收：`cmp src dst` 无输出；目标文件权限合理。

3. 目录统计器：`./dirstat <目录>` 输出「普通文件个数」和「普通文件总字节数」，目录与非普通文件不计入（用 `S_ISREG`）。
   提示：`readdir` 拿名字，`snprintf` 拼路径，再 `stat` 每个条目；注意 `.` 和 `..`。验收：与 `find . -maxdepth 1 -type f | wc -l` 的计数一致。

4. `mytail -n N <文件>`：打印文件最后 N 行（N 为正整数参数）。
   提示：先 `open` + `lseek(fd, 0, SEEK_END)` 得大小；从末尾往前逐字节读，数到第 N 个换行就停，再从该位置顺序输出。验收：与 `tail -n 3 sample.txt` 输出一致；文件不足 N 行时输出全部。

5. 给 3.8 的 `mywc` 增加 `-c` 选项：`./mywc -c file` 只输出字节数；与 `wc -c file` 对比。
   提示：`strcmp(argv[1], "-c") == 0`，然后从 `argv[2]` 开始处理文件。验收：`./mywc -c sample.txt` 输出 24。
