# 04 磁盘评估与外接固态硬盘建议

> 结论先说：**以你目前的机器和一年内的学习内容，不需要购买外接固态硬盘。**
> C 盘剩余 156.7 GB，WSL2 一年常规用量约 12~30 GB，完全放得下。
> 下面给出实测数据、估算过程，以及「什么时候才需要买」的量化条件。

## 一、实测数据（2026-09-19）

| 项目 | 数值 |
| --- | --- |
| C 盘 | 300 GB，剩余 **156.7 GB**（52.2%） |
| D 盘 | 174.7 GB，剩余 **94.9 GB**（54.3%） |
| 内存 | 23.7 GB |
| CPU | i5-13420H，12 逻辑线程 |
| 虚拟化 | 已开启（`HypervisorPresent = True`） |
| WSL2 | 未安装（基础占用很小，见下） |

## 二、WSL2 磁盘占用怎么算

WSL2 的 Ubuntu 是**动态增长**的虚拟磁盘 `ext4.vhdx`：用多少涨多少，不是一次性占满。

| 组成 | 预估占用 |
| --- | --- |
| WSL2 内核 + Ubuntu 24.04 基础 | 2~4 GB |
| 阶段 01 工具链（build-essential、git、tmux、python3-venv 等） | 2~4 GB |
| 阶段 02 科学栈（numpy、pandas、h5py、psutil、tqdm 等） | 2~3 GB |
| 阶段 03 C 工具链（gcc、gdb、valgrind） | 0.5~1 GB |
| 阶段 04 / 05 项目代码与虚拟环境 | 2~5 GB |
| 实验数据（建议放 D 盘） | 0~20 GB |
| **一年合计（常规）** | **约 12~30 GB** |

对比：若改用 VMware / VirtualBox 装完整 Ubuntu 桌面虚拟机，至少 25~60 GB，还要单独分配内存、文件互传麻烦，所以本路线用 WSL2。

## 三、结论与建议

1. **现在不需要外接固态硬盘**：C 盘剩余 156.7 GB、D 盘剩余 94.9 GB，远大于上面估算的需求；
2. 想更稳，可把 WSL 发行版迁到 D 盘（方法见 [01-WSL2与Ubuntu安装.md](01-WSL2与Ubuntu安装.md) 第 6 节），但这不是必需；
3. **数据分层**：代码与虚拟环境放 WSL 家目录（ext4）；原始实验数据、大文件、备份放 `/mnt/d`；处理中间结果尽量先拷进 ext4 再算（跨文件系统 IO 慢）；
4. **定期瘦身**（WSL 磁盘只增不减）：在 Windows PowerShell 执行

```powershell
wsl --shutdown
wsl --manage Ubuntu-24.04 --set-sparse true
```

Ubuntu 内查看占用：

```bash
df -h
du -sh ~
```

## 四、什么时候才需要买外接 SSD（量化触发条件）

满足任意一条再考虑：

- 单次实验数据超过 50 GB，且需要本地保存多份；
- 需要给论文与实验数据做离线备份 / 异地备份；
- 需要在多台电脑之间搬整套开发环境；
- C / D 盘合计剩余低于 20% 且清理无效。

选购建议（如果买）：

- USB 3.2 Gen2（10 Gbps）及以上、NVMe 移动固态，容量 ≥ 1 TB；
- 文件系统 NTFS 或 exFAT（Windows / Linux / 集群都能读写）；
- 定位是**归档与备份**；不建议把 WSL 的 `ext4.vhdx` 长期放外接盘上日常使用（USB 断电或接口松动可能导致文件系统损坏；临时迁移可以）。

## 五、备份习惯（比硬盘更重要的是备份）

- 每月：`wsl --export Ubuntu-24.04 D:\WSL\backup\ubuntu-2404-YYYYMMDD.tar`；
- 代码：Git 推送 GitHub（阶段 01 学）；数据：D 盘 + 移动盘双份；
- 备份文件不要和源数据放在同一块盘上。
